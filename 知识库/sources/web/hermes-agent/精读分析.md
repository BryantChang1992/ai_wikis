## 核心定位

Hermes Agent 自称 "The agent that grows with you"，是由 Nous Research 构建的自进化 AI Agent。与 LangChain/LangGraph/CrewAI/AutoGen 等传统 Agent 框架不同，Hermes 的核心差异化在于 **内建学习循环**（built-in learning loop）和 **主动编排层**（Active Orchestration Layer）。

2026 年 7 月达到 **140,000+ GitHub Stars**，被 OpenRouter 列为全球使用量最高的 Agent 应用。

## 四大核心差异化能力

### 1. Self-Evolving Skills（自进化 Skill）

基于 ICLR 2026 Oral 论文的 DSPy + GEPA 框架实现 skill 自进化。遇到复杂任务或收到反馈后，自动将经验保存为可复用 Skill。Skills 在使用过程中自我改进。兼容 agentskills.io 开放标准。

关键机制：
- Agent-curated memory with periodic nudges
- Autonomous skill creation after complex tasks
- Skills self-improve during use
- FTS5 session search with LLM summarization for cross-session recall
- Honcho dialectic user modeling

### 2. Contained Sub-Agents（隔离子 Agent）

子 Agent 作为短生命周期隔离 Worker，专注子任务，减少主 Agent 混乱。可 spawn 并行工作流，通过 RPC 调用工具，将多步 pipeline 压缩为零上下文开销的轮次。

### 3. Reliability by Design（设计可靠性）

Nous Research 对每个内置 skill/tool/plugin 进行压力测试。声称 30B 参数级模型即可稳定运行。

### 4. Active Orchestration Layer（主动编排层）

不是薄 wrapper，而是主动编排层。同一模型在不同框架下，Hermes 表现一致更强。支持 provider-agnostic（Anthropic / OpenAI / Google / DeepSeek + 本地 Ollama）。

## 行业意义

Hermes 的成功标志着 Agent 框架从"胶水代码时代"正式进入"编排引擎时代"：

1. **自进化能力** 解决了传统 Agent 框架"能力天花板由 prompt 决定"的瓶颈
2. **隔离子 Agent** 与 Microsoft CodeAct 的"模型写代码替代逐轮 tool call"思路形成互补——Hermes 降低框架复杂度，CodeAct 降低推理开销
3. **OpenRouter #1** 证明了自进化 Agent 在真实用户中的需求远高于链式工具调用

## 与已知框架的关系

当前知识库覆盖的 Agent Harness Engineering Survey 的 ETCLOVG 七层框架可以用于分析 Hermes 的架构设计。Hermes 在 Execution Environment（多后端）、Tool Interface（MCP+RPC）、Context Memory（Honcho user modeling）、Lifecycle Orchestration（子 Agent spawn+scheduler）四个维度都有独到设计。

## OpenClaw 迁移能力

Hermes 提供了 `hermes claw migrate` 命令，可自动从 OpenClaw 导入配置、记忆、Skills、API keys 等，体现了生态的开放性。
