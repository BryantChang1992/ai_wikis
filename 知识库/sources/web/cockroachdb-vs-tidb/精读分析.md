## 背景

2026 年分布式 SQL 数据库两大代表——CockroachDB 和 TiDB 已在生产环境积累了多年的运行经验。多家独立评测机构发布了年度对比分析。

## 核心对比维度

### 1. 架构哲学

| 维度 | CockroachDB | TiDB |
|------|------------|------|
| 架构风格 | 紧耦合多层（"像运行一台跨越 DC 的 PostgreSQL"） | 存算分离三组件（SQL + TiKV + TiFlash） |
| SQL 层 | 自研 SQL 引擎，PostgreSQL wire-compatible | 自研 SQL 引擎，MySQL wire-compatible |
| 存储层 | 自研 KV 存储引擎（Pebble/RocksDB 基础） | TiKV（Raft-based KV），可独立运行 |
| 分析引擎 | 内置列存支持 | TiFlash（独立列存组件） |

### 2. 地理分布式事务

- **CockroachDB 优势**：紧耦合架构使得地理分布式事务更"自然"——事务协调器与数据天然共址，延迟优化空间大
- **TiDB 方式**：通过 Placement Rules 控制数据分布，但事务协调需要跨越 TiDB Server → PD → TiKV 三层

### 3. 弹性扩缩

- **TiDB 优势**：存算分离 → SQL 层和存储层独立扩缩。OLTP 高峰可只扩 TiDB Server，数据搬迁成本低
- **CockroachDB 方式**：紧耦合 → 扩展需要增加完整节点，但也因此简化了容量规划

### 4. OLTP+OLAP 混合负载

- **TiDB + TiFlash**：列存副本通过 Raft Learner 同步，写入路径不经过列存，读请求可路由到列存
- **CockroachDB**：内置列存支持，但不如 TiFlash 独立组件灵活

### 5. 生态与兼容性

| 维度 | CockroachDB | TiDB |
|------|------------|------|
| SQL 兼容 | PostgreSQL | MySQL |
| 云服务 | CockroachDB Cloud (Serverless + Dedicated) | TiDB Cloud (Dedicated + Serverless Tier) |
| 开源许可 | BSL（Business Source License） | Apache 2.0 |
| 社区活跃度 | 中等 | 高（CNCF 毕业项目） |

## 选型建议

| 场景 | 推荐 | 原因 |
|------|------|------|
| PostgreSQL 生态用户 | CockroachDB | 原生 PG 兼容 |
| MySQL 生态用户 | TiDB | MySQL wire-compatible |
| 地理分布式事务 | CockroachDB | 紧耦合架构更自然 |
| 弹性 OLTP+OLAP | TiDB | 存算分离 + TiFlash |
| 纯 OLTP 大流量 | 均适用 | 性能接近 |
| 开源合规敏感 | TiDB | Apache 2.0 |
