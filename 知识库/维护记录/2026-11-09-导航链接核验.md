# 导航链接核验与检查器表格别名修复

## 本次修复

1. **三项误报**：Obsidian 表格使用 `\|` 分隔链接目标与显示别名。旧 `link_target` 按 `|` 切分后把反斜杠留在路径末尾，使团队核心规范、技术规范、Agent 核心文件三个已有 README 被误判为缺失。现在同时识别普通及转义分隔符，保留表格语法。
2. **两个目录目标**：[[团队规范/README]] 中的项目文档、知识库相关链接明确指向各自已有 README。
3. **两个项目目标**：[[团队规范/agent核心文件/README]] 的活跃项目指向已存在的设计文档；[[团队规范/团队核心规范/记忆管理规范]] 修正多一级目录造成的错误相对路径。只改导航，不改变规范或角色内容。
4. **一个同名歧义**：[[项目文档/Fluss源码分析/README]] 进度表中的整体架构对比使用项目完整路径，并保留原显示名称及表格别名转义。
