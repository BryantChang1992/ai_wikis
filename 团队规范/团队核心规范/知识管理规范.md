# 知识管理规范

2026-10-09：知识库维护以 [[知识库/schema]] 和根目录 AGENTS.md 为当前准则。ai_wikis 当前为公开仓库，沉淀范围限获准公开的材料；历史角色分工不扩大访问或发布授权。

## 知识沉淀路径

| 产出类型 | 写入路径 |
|---------|---------|
| 技术决策（选型、架构变更） | `work/ai_wikis/知识库/` |
| 新流程/方法/规范 | `work/ai_wikis/团队规范/` 对应领域 |
| 调研/分析结果 | `work/ai_wikis/技术文章/` |

## 沉淀流程

1. 任务完成后检查是否满足沉淀条件
2. 写入对应路径
3. 更新相关页、综述、索引与日志，运行结构检查和针对性语义审阅；只提交本次明确文件并读回远端
4. PMO 定期审查知识新鲜度

## PMO 职责

PMO 是知识沉淀的最终守门人：
- 审查所有 Agent 知识沉淀完整性
- 维护 ai_wikis 索引与分类
- 按已授权维护安排检查来源版本与有效边界；年龄只作为待复核提示，不自动标过期或删除
